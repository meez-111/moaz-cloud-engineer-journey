## 1. What is the AWS Certified Cloud Practitioner Certification?

The **AWS Certified Cloud Practitioner (CLF-C02)** is an entry‑level certification that validates foundational knowledge of the AWS Cloud.

It covers:

| Area | What You Learn |
|------|----------------|
| **Cloud Fundamentals** | Cloud concepts, cloud architecture, deployment models (public, private, hybrid). |
| **AWS Core Services** | Compute (EC2, Lambda), Storage (S3, EBS), Networking (VPC, Route 53), Databases (RDS, DynamoDB). |
| **Security and Compliance** | IAM, Shared Responsibility Model, compliance, encryption, AWS Shield, WAF. |
| **Billing and Pricing** | Pricing models (On‑Demand, Reserved, Spot), support plans, cost management. |
| **Support** | AWS Support plans (Basic, Developer, Business, Enterprise), Trusted Advisor. |

**Common abbreviation:** CCP = Cloud Practitioner.

---

## 2. Who Is This Certification For?

The Cloud Practitioner certification is designed for **people new to the cloud**. It is **not** a deeply technical, hands‑on exam – it is conceptual.

**Ideal candidates:**

- **Sales / marketing / business roles** – understanding AWS services to position solutions.
- **Project managers** – managing cloud projects without deep implementation.
- **Junior developers / system administrators** – starting their cloud journey.
- **Non‑technical roles** – compliance, finance, procurement.

**For you (Moaz):** You already have hands‑on experience with EC2, Linux, and Docker. While this cert is foundational, it fills gaps (IAM, VPC, pricing, global infrastructure) and provides a clear path to the **AWS Solutions Architect – Associate** (which is your ultimate target for cloud engineering roles).

## 4. Exam Guide – Content Outline

The CLF-C02 exam consists of **4 domains**, each with a specific weighting.

### 4.1 Domain 1: Cloud Concepts (24%)

| Topic | Key Concepts |
|-------|--------------|
| Benefits of AWS Cloud | Cost savings, scalability, elasticity, high availability, global reach. |
| Cloud economics | CAPEX vs. OPEX, pay‑as‑you‑go. |
| Design principles | Well‑Architected Framework (operational excellence, security, reliability, performance efficiency, cost optimisation, sustainability). |
| Shared Responsibility Model | AWS vs. customer responsibilities. |
| Cloud deployment models | Public, private, hybrid. |

**Sample question:** "Which of the following is a benefit of the AWS Cloud? (A) Fixed pricing (B) Unlimited storage (C) Pay‑as‑you‑go (D) No need for security)"

### 4.2 Domain 2: Security and Compliance (30%)

| Topic | Key Concepts |
|-------|--------------|
| IAM | Users, Groups, Roles, Policies, MFA, least privilege. |
| Shared Responsibility Model | Detailed breakdown. |
| AWS security services | AWS Shield (DDoS), WAF (web application firewall), KMS (key management), CloudTrail (audit logging), Config (compliance). |
| Compliance | GDPR, HIPAA, SOC, ISO. |
| AWS Well‑Architected Framework | Security pillar. |

**Sample question:** "Which AWS service helps you audit API calls? (A) CloudWatch (B) CloudTrail (C) Config (D) Shield)"

### 4.3 Domain 3: Technology (34%)

| Topic | Key Concepts |
|-------|--------------|
| AWS Global Infrastructure | Regions, AZs, Edge Locations. |
| Compute | EC2 (instance families, AMIs, pricing models), Lambda (serverless), Elastic Beanstalk. |
| Storage | S3 (buckets, objects, storage classes), EBS (volumes), EFS (file storage), Glacier. |
| Networking | VPC (subnets, IGW, NAT, Route Tables), CloudFront (CDN), Route 53 (DNS). |
| Databases | RDS (relational), DynamoDB (NoSQL), ElastiCache (caching). |
| Application services | API Gateway, SQS, SNS (messaging). |

**Sample question:** "Which AWS service is a NoSQL database? (A) RDS (B) DynamoDB (C) Redshift (D) Aurora)"

### 4.4 Domain 4: Billing and Pricing (12%)

| Topic | Key Concepts |
|-------|--------------|
| Pricing models | On‑Demand, Reserved (standard, convertible), Spot, Savings Plans. |
| AWS Cost Management | Cost Explorer, Budgets, AWS Pricing Calculator. |
| Support plans | Basic (free), Developer, Business, Enterprise. |
| AWS Marketplace | Third‑party software listings. |

**Sample question:** "Which pricing model provides the highest discount for consistent workloads? (A) On‑Demand (B) Spot (C) Reserved (D) Savings Plans)"

## 5. Exam Details – Grading, Duration, Questions

| Detail | Information |
|--------|-------------|
| **Passing score** | 700 / 1000 |
| **Total questions** | 65 |
| **Scored questions** | 50 |
| **Unscored questions** | 15 (not identified – you don't know which are scored) |
| **Duration** | 120 minutes total (90 minutes for the exam + 30 minutes for NDA and survey) |
| **Question types** | Multiple‑choice, multiple‑response |
| **Validity** | 3 years (recertification required) |
| **Format** | Online proctored (Pearson VUE) or at a test centre. |

**Key tips:**
- The 15 unscored questions are experimental – answer them as if they were scored.
- Manage your time: ~1.5 minutes per question.
- Mark questions you're unsure about and return to them.
