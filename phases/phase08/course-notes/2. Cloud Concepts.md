## 1. What is Cloud Computing?

**Cloud computing** is the practice of using a network of remote servers hosted on the internet to store, manage, and process data, rather than using a local server or a personal computer.

### On‑Premises vs. Cloud

| Aspect | On‑Premises (Traditional) | Cloud (AWS, Azure, GCP) |
|--------|---------------------------|-------------------------|
| **Ownership** | You own the servers. | Someone else owns the servers. |
| **Staffing** | You hire and manage IT personnel. | The provider manages infrastructure staff. |
| **Real estate** | You pay for or rent physical space, power, cooling. | No real estate costs. |
| **Risk** | You bear all risks (hardware failure, security, compliance). | Provider shares the responsibility. |
| **Cost model** | Capital expenditure (CAPEX) – large upfront investment. | Operational expenditure (OPEX) – pay‑as‑you‑go. |

## 2. Evolution of Cloud Hosting

| Era | Model | Description | Pros | Cons |
|-----|-------|-------------|------|------|
| **1990s – 2000s** | **Dedicated Server** | One physical machine for one single business, running a single application. | Full control, dedicated resources. | Very expensive, high maintenance, high security risk, underutilisation. |
| **2000s – 2010s** | **VPS (Virtual Private Server)** | One physical machine virtualised into multiple sub‑machines. Each business gets its own isolated VM. | Better resource utilisation, isolation, more affordable. | Still requires management of the OS and applications. |
| **2000s – Present** | **Shared Hosting** | Multiple websites share the same server resources (CPU, memory, storage). | Very cheap, easy to set up. | Limited resources, security risks (neighbour sites can affect you). |
| **2010s – Present** | **Cloud Hosting** | Massive, distributed infrastructure. Resources are provisioned on‑demand, scaling automatically. | Pay‑as‑you‑go, unlimited scalability, high availability, global reach. | Requires new skills (cloud architecture, security, cost management). |

## 4. What is AWS?

**AWS (Amazon Web Services)** is the world's leading cloud service provider. It was launched internally in 2004 with the first service, **SQS (Simple Queue Service)**, and later **S3 (2006)** and **EC2 (2006)**.

| Key Facts | Details |
|-----------|---------|
| **Launched** | 2006 (publicly) |
| **Headquarters** | Seattle, Washington, USA |
| **First service** | SQS (Simple Queue Service) – 2004 |
| **Market share** | ~30‑35% of the cloud market |
| **Number of services** | Over 200 |
| **Regions** | 37 (as of 2025) |
| **Availability Zones** | Over 100 |

**Why AWS dominates:**
- First mover advantage (started in 2006).
- Broadest and deepest service portfolio.
- Massive global infrastructure.
- Strong partner and community ecosystem.
- Continuous innovation (new services and features every year).

## 5. What is a CSP (Cloud Service Provider)?

A **Cloud Service Provider (CSP)** is a company that offers cloud computing services to customers. Characteristics of a CSP:

| Characteristic | Description |
|----------------|-------------|
| **Multiple services** | Offers tens to hundreds of cloud services (compute, storage, networking, databases, AI, etc.). |
| **Chaining / Integration** | Services can be chained together to create complex cloud architectures. |
| **Unified API** | Accessible via a single unified API (e.g., AWS API). |
| **Metered billing** | Usage‑based billing (e.g., per second, per hour, per GB). |
| **Rich monitoring** | Built‑in monitoring and logging (e.g., AWS CloudTrail, CloudWatch). |
| **IaaS offering** | Provides Infrastructure as a Service (raw compute, storage, networking). |
| **Automation** | Supports Infrastructure as Code (IaC) – e.g., AWS CloudFormation, Terraform. |

## 10. Evolution of Computing – Dedicated, VMs, Containers, Serverless

| Model | Description | Level of Control | AWS Service |
|-------|-------------|------------------|-------------|
| **Dedicated / Bare Metal** | Physical server, full control over hardware. | Highest | EC2 Bare Metal |
| **Virtual Machines (VMs)** | Virtualised compute; you manage the OS and applications. | High | EC2 |
| **Containers** | Lightweight, share the host OS kernel; faster startup. | Medium | ECS, EKS |
| **Serverless (Functions)** | Run code without provisioning or managing servers. | Lowest | Lambda |

**Key trend:** Moving from **infrastructure management** to **code‑only management**. Serverless removes the need to manage OS patching, scaling, and capacity planning.

## 11. Types of Cloud Computing – IaaS, PaaS, SaaS

| Model | Definition | What You Manage | What Provider Manages | AWS Example |
|-------|------------|-----------------|-----------------------|-------------|
| **IaaS** (Infrastructure as a Service) | Raw compute, storage, and networking. | OS, applications, data, networking. | Hardware, virtualization, storage infrastructure. | **EC2** |
| **PaaS** (Platform as a Service) | Platform for developing and deploying applications. | Application code, data. | OS, runtime, middleware, infrastructure. | **Elastic Beanstalk**, **Lambda** |
| **SaaS** (Software as a Service) | Fully functional applications delivered over the internet. | User data, configuration. | Everything else. | **Amazon WorkSpaces**, **Office 365** |

## 12. Cloud Computing Deployment Models

| Model | Description | Use Case |
|-------|-------------|----------|
| **Public Cloud** | Resources are shared across multiple tenants (organisations). Everything is built on the CSP. | Web apps, mobile backends, dev/test environments. |
| **Private Cloud (On‑Premises)** | Resources are dedicated to a single organisation. Can be on‑premises or hosted by a third party. | Sensitive data, strict compliance (healthcare, finance). |
| **Hybrid Cloud** | Combination of public and private clouds. Resources are shared between them. | Gradual migration, bursting (public for spikes), DR. |
| **Cross‑Cloud (Multi‑Cloud)** | Using multiple public cloud providers simultaneously. | Avoid vendor lock‑in, best‑of‑breed services, disaster recovery. |

**Deployment Models Use Cases:**

| Scenario | Recommended Model |
|----------|-------------------|
| Startup building a new web app from scratch | **Public Cloud** (cloud‑native) |
| Bank with strict data residency and compliance requirements | **Private Cloud** (on‑premises) |
| Company with legacy systems that are hard to migrate, but wants to use cloud for elastic workloads | **Hybrid Cloud** |
| Enterprise that wants to avoid dependency on a single cloud vendor and use multiple CSPs | **Cross‑Cloud (Multi‑Cloud)** |

## 13. The 6 Advantages of Cloud Computing

According to AWS, the six advantages of cloud computing are:

| # | Advantage | Explanation |
|---|-----------|-------------|
| **1** | **Trade capital expense for variable expense** | No need to buy servers upfront. You pay only for what you use (OPEX instead of CAPEX). |
| **2** | **Benefit from massive economies of scale** | AWS can offer lower prices because of its scale (e.g., better purchasing power for hardware). |
| **3** | **Stop guessing about capacity** | You can scale up or down instantly – no more over‑provisioning or under‑provisioning. |
| **4** | **Increase speed and agility** | Launch resources in minutes, not weeks or months. |
| **5** | **Stop spending money on running and maintaining data centres** | No need for cooling, power, security, or physical maintenance. |
| **6** | **Go global in minutes** | Deploy applications in multiple regions worldwide with a few clicks. |

## 15. Practice Lab – Verify Your Understanding

1. **Define cloud computing in your own words.**

2. **Identify the model:**  
   A startup builds a web application using AWS Lambda, API Gateway, and DynamoDB. Which deployment model is this? (Public Cloud.)

3. **CAPEX vs. OPEX:**  
   You purchase a Reserved Instance for 3 years. Is this CAPEX or OPEX? (OPEX – because it's still a pay‑as‑you‑go cloud service, even with upfront payment. Traditional CAPEX involves buying physical hardware.)

4. **CSP characteristics:**  
   List three characteristics of a Cloud Service Provider.

   Rank the following from most control to least control: Containers, VMs, Serverless, Dedicated. (Dedicated → VMs → Containers → Serverless.)

6. **6 Advantages:**  
   Which advantage of cloud computing allows you to deploy in `us-east-1`, `eu-west-1`, and `ap-southeast-2` in minutes? (Go global in minutes.)
